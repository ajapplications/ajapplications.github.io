Security

Security principles.

AJ APPLICATIONS takes security seriously across its products, without overstating what any system can guarantee.

Responsible disclosure

If you find a security issue in an AJ APPLICATIONS product, please report it through the contact page before disclosing it publicly. Reports are reviewed as time allows, given the studio's independent size.

Authentication

Products that require accounts (such as Castrix) use standard authentication flows. Anonymous products (such as NovaTalk) are designed to avoid requiring an account at all.

Data handling

Data handling varies by product. NEXAVAULT is designed so files stay on hardware the owner controls; other products may store data on shared infrastructure. See the Privacy page for product-specific detail.

Infrastructure security

Deployments use standard practices such as containerization (Docker) where applicable, and access controls scoped to what each service actually needs.

Privacy considerations

Privacy is treated as a design input, not an afterthought. That does not mean every product is anonymous or encrypted end-to-end — only what's actually implemented is claimed.

AJ APPLICATIONS does not claim any product is unhackable, 100% secure, or protected by "military-grade" security. No software can honestly make that guarantee.
